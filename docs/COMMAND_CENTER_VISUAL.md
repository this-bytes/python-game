## Color Scheme

**Background**:
- Primary: #0a0e27 (Deep space blue)
- Secondary: #151937 (Dark panel)
- Tertiary: #1e2442 (Card background)

**Accents**:
- Primary: #00ff88 (Neon green) - Success, available
- Secondary: #00ccff (Cyan) - Information, highlights
- Danger: #ff3366 (Pink/red) - Errors, critical
- Warning: #ffcc00 (Yellow) - Warnings, busy

**Text**:
- Primary: #ffffff (White) - Main text
- Secondary: #8892b0 (Blue-gray) - Labels
- Tertiary: #4a5578 (Muted) - Less important

## Animations

**Window Open**:
- Fade in (0.3s)
- Slide up (20px)

**Desktop Icon Hover**:
- Lift up (5px)
- Glow effect (shadow)
- Border highlight

**Entity Card Hover**:
- Lift up (3px)
- Shadow intensify
- Border glow

**Notification**:
- Slide in from right (0.3s)
- Auto-dismiss after 3s
- Fade out (0.3s)

## Responsive Breakpoints

**Desktop (1200px+)**:
- Full multi-window experience
- Grid: 6 columns for icons
- Windows can overlap
- All features enabled

**Tablet (768-1200px)**:
- Simplified grid (4 columns)
- Windows stack better
- Touch-optimized targets
- Some features adjusted

**Mobile (<768px)**:
- Single column icons
- One window at a time
- Touch-first interface
- Simplified workflows

## Typography

**Headings**: Orbitron (Display font)
- Logo: 24px, 900 weight
- Window titles: 16px, 700 weight
- Metric values: 32px, 700 weight

**Body**: Rajdhani (Body font)
- Regular text: 14px, 400 weight
- Labels: 11px, 600 weight
- Buttons: 14px, 700 weight

## Status Indicators

- 🟢 **Green**: Available, Online, Good
- 🟡 **Yellow**: Busy, Warning, Moderate
- 🔴 **Red**: Critical, Offline, Urgent
