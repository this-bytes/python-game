## THE GAME YOU'RE BUILDING

### Title
**SOC Startup Management Tycoon**

### Core Concept
Manage a Security Operations Center startup with:
- Multiple clients with different threat landscapes
- Monthly budget cycles with bankruptcy risk
- Strategic specialist assignment to incidents
- SLA tracking affecting client satisfaction
- Prestige progression for replayability

### Why It Works
✅ Authentic (matches real SOC operations)
✅ Interconnected (budget affects hiring, affects SLA, affects revenue)
✅ Strategic (multiple viable winning paths)
✅ Consequential (fair failure states, not random)
✅ Replayable (prestige system with new game+)

### The Game Loop (Monthly)
```
1. Review client portfolio, budget, incidents
2. Assign specialists to incident queue
3. Auto-resolve incidents (success probability based on skill)
4. Track SLA performance per client
5. Calculate revenue (contract value × satisfaction)
6. Calculate expenses (salaries + infrastructure)
7. Check: Bankrupt? Contracts renewing?
8. Progress to next month or new game+
```
