# 🎮 CYBERSECURITY FIRM TYCOON - PLAYER GUIDE

## Welcome to Your Cybersecurity Firm!

This is an **Active Strategy Tycoon with Idle Elements**. You make strategic decisions about incident assignment, build your team, and watch your firm grow!

---

## ⚡ Core Gameplay: Decision-Based Assignment

### How It Works
- **Incidents spawn continuously** from your client contracts
- **YOU decide who handles what** - strategic assignment is key
- **Specialists resolve incidents** and earn XP/money
- **Automation helps later** - unlock scripts to handle routine incidents
- **Stay engaged** - this game rewards active decision-making!

### What You See
```
Top-right corner:
┌─────────────────────────┐
│ ✓ AUTO-PLAY ACTIVE      │
│ Threshold: Difficulty ≤3│
│ (Press A to toggle)     │
└─────────────────────────┘
```

**Green = AUTO-PLAY ON** (default)  
**Red = AUTO-PLAY OFF** (manual mode)

## ⚡ Synergy System: Strategic Depth

### What Are Synergies?
Each specialist has **2 special threat types** they're experts at. When they handle matching incidents, they get **MASSIVE BONUSES**:

- 🔥 **1.5x - 2.5x XP**
- 💰 **1.2x - 1.8x Money**
- ⚡ **1.3x - 1.8x Speed**
- ✅ **+10% - +20% Success Rate**

### Example Specialist
```
Alice Chen (Network Security) - Level 5
Synergies:
  🎯 DDoS Attack: 2.5x XP, 1.8x $, 1.8x speed
  🎯 SQL Injection: 1.5x XP, 1.5x $, 1.3x speed
```

When Alice handles a DDoS Attack, she earns **2.5x XP** and **1.8x money**!

## 🎮 How To Play

### Idle Mode (Default)
1. **Start the game**
2. Watch incidents appear and auto-assign
3. Check synergy panel (Press S) occasionally
4. Manually assign high-synergy incidents for bonuses
5. **Close the game** whenever you want
6. Come back later for offline rewards!

### Active Mode
1. Press **A** to toggle auto-play OFF
2. Manually assign all incidents yourself
3. Use synergy panel to find best matches
4. Press **A** again to re-enable auto-play

### Recommended Strategy
- **Leave auto-play ON** for most incidents
- **Press S** to check synergy opportunities every minute
- **Manually assign** when you see 🔥 URGENT synergies
- Let everything else auto-assign

## 🤖 Automation (Late Game)

### How It Works
As you progress, unlock automation scripts that handle routine incidents:
1. **Early Game (1-10)**: Manual assignment of every incident
2. **Mid Game (10-20)**: Scripts handle ~50% (low-difficulty incidents)
3. **Late Game (20-30)**: Scripts handle ~80% (everything routine)

### Automation Rules
```
Example Script:
IF incident.difficulty <= 3 AND
   incident.type == "DDoS" AND
   specialist.specialty == "Network Security"
THEN auto-assign

Result: You focus on complex incidents only!
```

### Why Automation?
- **Not for offline play** - it reduces tedium during active play
- **Strategic tool** - you configure the rules
- **Late-game reward** - earned through progression
- **You stay in control** - can always manually override

- Unlock permanent bonuses (XP multiplier, starting money, etc.)
- Reset and do it again with advantages
